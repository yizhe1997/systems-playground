## Notes

- Every figure an agent reads is produced by the same handler as the screen; no tool re-implements a query.
- A change and its audit entry are one transaction; an agent read is refused if its entry cannot be written.
- No token value is written to a file in the repository, a log, a screenshot, an error message or an audit row; after creation the only place it exists is the owner's agent configuration (and the e2e temp file outside the repository, for the secret check).
- A deviation from `screens.md` is either a defect (fix it) or a decision (ask the owner and update the Penpot frame in the same change).
- Commit after each task or small group, on the single branch `tradecraft_v2`; push nothing without the owner's say-so.
